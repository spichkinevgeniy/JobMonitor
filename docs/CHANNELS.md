# Каналы с вакансиями

В файле [`channels_map.json`](../channels_map.json) каналы сгруппированы по направлениям. Канал можно указать как ссылку `https://t.me/channel_name`, имя `@channel_name` или числовой ID. Для публичных каналов лучше использовать ссылку: её проще проверить.

## Категории

- `Python` — Python;
- `JavaScript` — frontend, React, Vue, Angular и другие веб-технологии;
- `JAVA` — Java и общий JVM-backend;
- `KOTLIN` — Kotlin;
- `GO` — Go;
- `C#` — .NET;
- `C++`, `RUST`, `RUBY`, `PHP`, `NODEJS` — соответствующие языки;
- `ML` — Data Science и машинное обучение;
- `ANALYTICS` — аналитика и работа с данными;
- `MOBILE` — мобильная разработка;
- `GAMEDEV` — игровая разработка;
- `DEVOPS` — DevOps и SRE;
- `QA` — тестирование;
- `Common` — несколько направлений без одного основного.

Категория должна соответствовать тегу, который бот умеет проставлять. Заводить категорию под направление, которого нет в `SkillType`, бессмысленно: вакансии из неё всё равно разойдутся по соседним тегам.

Если канал подходит к нескольким категориям, выберите его основную тему. Если её нельзя определить, используйте `Common`.

## Как добавить канал

- добавьте канал в ближайшую по смыслу категорию;
- проверьте, что такого канала ещё нет;
- не оставляйте пустые значения;
- сохраняйте формат ссылок, который уже используется в категории;
- для приватного канала проверьте, что аккаунт Telethon вступил в него и видит сообщения.
